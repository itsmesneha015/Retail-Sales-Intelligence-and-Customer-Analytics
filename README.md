# Retail Sales Intelligence and Customer Analytics System

An AI-powered retail analytics system that combines sales analysis, machine learning-based forecasting, seasonal demand analysis, computer vision-based customer analytics, anomaly detection, and a multilingual AI assistant in an interactive Streamlit dashboard.

## 🚀 Live Demo

Streamlit App:
https://retail-sales-intelligence-and-customer-analytics-y87fmfjgas7d6.streamlit.app/

## 📌 Project Overview

The Retail Sales Intelligence and Customer Analytics System is designed to help retail businesses understand sales performance, customer behavior, demand patterns, and future trends through an interactive dashboard.

The system combines:

- Retail sales analytics
- Profit and profit margin analysis
- Seasonal demand analysis
- Machine learning-based sales forecasting
- Computer vision-based customer analytics
- Customer dwell-time analysis
- Store zone analytics
- Sales anomaly detection
- AI business chatbot
- Multilingual voice assistant
- Business insights and reporting

The complete application is developed using Python and Streamlit.

## 🎯 Objectives

1. Analyze retail sales and profit performance.
2. Identify important sales and demand patterns.
3. Predict future sales using machine learning.
4. Analyze seasonal demand and category performance.
5. Analyze customer entry, exit, occupancy, and dwell time.
6. Analyze customer activity across store zones.
7. Detect unusual sales patterns using anomaly detection.
8. Provide business insights from the available data.
9. Allow users to interact with the dashboard using natural-language questions.
10. Support English, Kannada, and Hindi voice interaction.
