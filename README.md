# Retail Sales Analytics Dashboard with Sales Forecasting

## 📌 Project Overview

This project is an end-to-end Retail Sales Analytics Dashboard that analyzes historical retail sales data and predicts future sales using Machine Learning.

The project helps businesses understand sales performance, customer behavior, product performance, and future sales trends through interactive visualizations.

---

## 🎯 Objectives

- Analyze retail sales data
- Perform data cleaning and preprocessing
- Create interactive visualizations
- Build Machine Learning models
- Forecast future sales
- Develop an interactive Streamlit dashboard

---
